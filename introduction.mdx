## What is Anserini?

Anserini is an open-source information retrieval toolkit built on Apache Lucene. It provides researchers and developers with a comprehensive platform for:

- **Reproducible IR Research** — End-to-end regression testing ensures experiments are reproducible
- **Multiple Retrieval Models** — BM25, dense vectors, learned sparse representations, and hybrid approaches
- **Prebuilt Indexes** — Ready-to-use indexes for MS MARCO, BEIR, and TREC collections
- **Neural Encoders** — Integration with modern dense and sparse encoders including SPLADE, BGE, and ONNX models
- **Production-Ready** — Published to Maven Central as a library and available as a self-contained fatjar

## Quick Example

Run BM25 retrieval on MS MARCO passage corpus using the fatjar:

```bash
# Download the fatjar
wget https://repo1.maven.org/maven2/io/anserini/anserini/1.6.0/anserini-1.6.0-fatjar.jar

# Run BM25 search
java -cp anserini-1.6.0-fatjar.jar io.anserini.search.SearchCollection \
  -index msmarco-v1-passage \
  -topics msmarco-v1-passage.dev \
  -output run.msmarco-v1-passage.dev.bm25.txt \
  -bm25

# Evaluate results
java -cp anserini-1.6.0-fatjar.jar trec_eval -c -M 10 -m recip_rank \
  msmarco-v1-passage.dev run.msmarco-v1-passage.dev.bm25.txt
```

Expected MRR@10: **0.1840**

## Why Anserini?

<AccordionGroup>
  <Accordion title="Reproducibility First">
    Anserini is designed from the ground up for reproducible research. Every regression experiment can be reproduced exactly, with automated verification of effectiveness scores.
  </Accordion>
  
  <Accordion title="Battle-Tested at Scale">
    Built on Apache Lucene 9.9.1, Anserini inherits decades of production-hardened search technology used by organizations worldwide.
  </Accordion>
  
  <Accordion title="Modern Neural IR">
    Native support for dense vector search, learned sparse representations, and ONNX model integration brings state-of-the-art neural IR to a proven Lucene foundation.
  </Accordion>
  
  <Accordion title="Research to Production">
    Anserini bridges the gap between academic IR research and real-world applications. Experiments run in Anserini can inform production search systems.
  </Accordion>
</AccordionGroup>

## Research Impact

Anserini grew out of a reproducibility study of open-source retrieval engines in 2016. The toolkit has been cited in hundreds of research papers and powers IR experiments at universities and research labs worldwide.

<Card title="Read the Papers" icon="book-open" href="https://dl.acm.org/doi/10.1145/3239571">
  See the JDIQ 2018 paper for an overview of Anserini's design and goals
</Card>

## Related Projects

Anserini is part of a broader ecosystem:

- **[Pyserini](http://pyserini.io/)** — Python interface to Anserini with additional features
- **Lucene** — The underlying search library powering Anserini
- **TREC** — Standard IR evaluation campaigns that Anserini supports
