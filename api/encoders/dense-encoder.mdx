## Overview

The `DenseEncoder` abstract class provides an interface for encoding text into dense vector representations using ONNX-based neural models. Dense encoders are used for semantic search and neural retrieval applications.

## Class Hierarchy

```
OnnxEncoder<float[]>
  └── DenseEncoder
        ├── BgeBaseEn15Encoder
        ├── BgeLargeEn15Encoder
        ├── ArcticEmbedLEncoder
        └── CosDprDistilEncoder
```

## Available Implementations

### BgeBaseEn15Encoder

BAAI's BGE-base-en-v1.5 encoder for English text.

```java
import io.anserini.encoder.dense.BgeBaseEn15Encoder;
import ai.onnxruntime.OrtException;
import java.io.IOException;
import java.net.URISyntaxException;

public class BgeExample {
    public static void main(String[] args) 
            throws IOException, OrtException, URISyntaxException {
        // Initialize encoder
        BgeBaseEn15Encoder encoder = new BgeBaseEn15Encoder();
        
        // Encode a query
        String query = "What is information retrieval?";
        float[] embedding = encoder.encode(query);
        
        System.out.println("Embedding dimension: " + embedding.length);
        System.out.println("First 5 values: ");
        for (int i = 0; i < 5; i++) {
            System.out.printf("  %.4f%n", embedding[i]);
        }
        
        // Clean up resources
        encoder.close();
    }
}
```

**Features:**
- Model: BGE-base-en-v1.5 (BAAI)
- Embedding dimension: 768
- Max sequence length: 512 tokens
- Automatic L2 normalization
- Query instruction prepending

## Usage Patterns

### Basic Encoding

```java
import io.anserini.encoder.dense.BgeBaseEn15Encoder;

try (BgeBaseEn15Encoder encoder = new BgeBaseEn15Encoder()) {
    float[] queryEmbedding = encoder.encode("search query");
    float[] docEmbedding = encoder.encode("document text");
    
    // Compute similarity (dot product for normalized vectors)
    float similarity = 0.0f;
    for (int i = 0; i < queryEmbedding.length; i++) {
        similarity += queryEmbedding[i] * docEmbedding[i];
    }
    System.out.println("Similarity: " + similarity);
} catch (Exception e) {
    e.printStackTrace();
}
```

### Batch Processing

```java
import io.anserini.encoder.dense.BgeBaseEn15Encoder;
import java.util.ArrayList;
import java.util.List;

try (BgeBaseEn15Encoder encoder = new BgeBaseEn15Encoder()) {
    List<String> documents = List.of(
        "First document",
        "Second document",
        "Third document"
    );
    
    List<float[]> embeddings = new ArrayList<>();
    for (String doc : documents) {
        embeddings.add(encoder.encode(doc));
    }
    
    System.out.println("Encoded " + embeddings.size() + " documents");
} catch (Exception e) {
    e.printStackTrace();
}
```

### Custom Normalization

```java
import io.anserini.encoder.dense.DenseEncoder;
import io.anserini.encoder.dense.BgeBaseEn15Encoder;

try (BgeBaseEn15Encoder encoder = new BgeBaseEn15Encoder()) {
    float[] raw = encoder.encode("text to encode");
    
    // Vectors are already normalized, but you can re-normalize if needed
    float[] normalized = DenseEncoder.normalize(raw);
    
    // Verify L2 norm
    float norm = 0.0f;
    for (float v : normalized) {
        norm += v * v;
    }
    System.out.println("L2 norm: " + Math.sqrt(norm)); // Should be ~1.0
} catch (Exception e) {
    e.printStackTrace();
}
```

## Model Caching

All dense encoders automatically cache models and vocabularies in:

```
~/.cache/pyserini/encoders/
```

Models are downloaded once on first use and reused in subsequent runs.

## Resource Management

Dense encoders implement `AutoCloseable` for proper resource cleanup:

```java
// Using try-with-resources (recommended)
try (BgeBaseEn15Encoder encoder = new BgeBaseEn15Encoder()) {
    float[] embedding = encoder.encode("query");
    // encoder.close() called automatically
}

// Manual cleanup
BgeBaseEn15Encoder encoder = new BgeBaseEn15Encoder();
try {
    float[] embedding = encoder.encode("query");
} finally {
    encoder.close();
}
```
