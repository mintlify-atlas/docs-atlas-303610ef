## Overview

Anserini provides two dense vector search implementations:

1. **`HnswDenseSearcher`** - Approximate nearest neighbor search using Hierarchical Navigable Small World (HNSW) graphs
2. **`FlatDenseSearcher`** - Exact nearest neighbor search using brute-force comparison

Both support vector-based search with pre-computed embeddings or on-the-fly encoding using dense encoders.

**Package**: `io.anserini.search`

**Source**: 
- `src/main/java/io/anserini/search/HnswDenseSearcher.java`
- `src/main/java/io/anserini/search/FlatDenseSearcher.java`

## HnswDenseSearcher

Approximate nearest neighbor search using HNSW indexes for fast vector similarity search.

public HnswDenseSearcher(Args args)

<ParamField path="args" type="HnswDenseSearcher.Args" required>

### Args Class

The `Args` class extends `BaseSearchArgs`:

<ParamField path="index" type="String" required>

</ParamField>

<ParamField path="encoder" type="String">

<ParamField path="generator" type="String" default="VectorQueryGenerator">

</ParamField>

<ParamField path="quiet" type="boolean" default="false">
  Suppress logging except errors
</ParamField>

## FlatDenseSearcher

Exact nearest neighbor search using brute-force vector comparison. Slower than HNSW but guarantees exact results.

### Constructor

```java
public FlatDenseSearcher(Args args)
```

Initializes a flat dense searcher.

<ParamField path="args" type="FlatDenseSearcher.Args" required>
  Configuration object
</ParamField>

### Args Class

<ParamField path="index" type="String" required>
  Path to the vector index directory
</ParamField>

<ParamField path="encoder" type="String">
  Dense encoder class name
</ParamField>

<ParamField path="generator" type="String" default="VectorQueryGenerator">
  QueryGenerator class to use
</ParamField>

<ParamField path="quiet" type="boolean" default="false">
  Suppress logging except errors
</ParamField>

### Search Methods

FlatDenseSearcher provides the same search methods as HnswDenseSearcher:

- `search(float[] query, int k)`
- `search(K qid, float[] query, int k)`
- `search(String query, int k)`
- `search(K qid, String query, int k)`
- `batch_search(List<String> queries, List<K> qids, int k, int threads)`
- `close()`

See HnswDenseSearcher documentation above for method signatures and parameters.

## Usage Examples

### HNSW Search with Pre-computed Vectors

```java
import io.anserini.search.HnswDenseSearcher;
import io.anserini.search.ScoredDoc;

public class HnswExample {
  public static void main(String[] args) throws Exception {
    HnswDenseSearcher.Args searchArgs = new HnswDenseSearcher.Args();
    searchArgs.index = "/path/to/hnsw/index";
    searchArgs.efSearch = 100;
    
    try (HnswDenseSearcher<String> searcher = new HnswDenseSearcher<>(searchArgs)) {
      // Query vector (e.g., from a neural encoder)
      float[] queryVector = new float[768]; // 768-dimensional embedding
      // ... populate queryVector ...
      
      ScoredDoc[] results = searcher.search(queryVector, 10);
      
      for (int i = 0; i < results.length; i++) {
        System.out.printf("%d. %s (similarity: %.4f)\n",
            i + 1, results[i].docid, results[i].score);
      }
    }
  }
}
```

### Batch Search with HNSW

```java
import io.anserini.search.HnswDenseSearcher;
import java.util.*;

public class HnswBatchExample {
  public static void main(String[] args) throws Exception {
    HnswDenseSearcher.Args searchArgs = new HnswDenseSearcher.Args();
    searchArgs.index = "/path/to/hnsw/index";
    searchArgs.encoder = "Ance";  // ANCE encoder
    searchArgs.efSearch = 100;
    
    try (HnswDenseSearcher<String> searcher = new HnswDenseSearcher<>(searchArgs)) {
      List<String> queries = Arrays.asList(
          "What is deep learning?",
          "How does neural search work?",
          "Best practices for information retrieval"
      );
      List<String> qids = Arrays.asList("1", "2", "3");
      
      SortedMap<String, ScoredDoc[]> results = 
          searcher.batch_search(queries, qids, 10, 8);
      
      for (Map.Entry<String, ScoredDoc[]> entry : results.entrySet()) {
        System.out.println("Query " + entry.getKey() + ":");
        for (int i = 0; i < entry.getValue().length; i++) {
          System.out.printf("  %d. %s (%.4f)\n",
              i + 1, entry.getValue()[i].docid, entry.getValue()[i].score);
        }
      }
    }
  }
}
```

### Comparing HNSW vs Flat Search

```java
import io.anserini.search.*;
import java.util.*;

public class CompareSearchers {
  public static void main(String[] args) throws Exception {
    String query = "information retrieval techniques";
    int k = 100;
    
    // HNSW (approximate)
    HnswDenseSearcher.Args hnswArgs = new HnswDenseSearcher.Args();
    hnswArgs.index = "/path/to/hnsw/index";
    hnswArgs.encoder = "TasB";
    hnswArgs.efSearch = 100;
    
    long hnswStart = System.currentTimeMillis();
    try (HnswDenseSearcher<String> hnswSearcher = new HnswDenseSearcher<>(hnswArgs)) {
      ScoredDoc[] hnswResults = hnswSearcher.search(query, k);
      long hnswTime = System.currentTimeMillis() - hnswStart;
      System.out.println("HNSW search time: " + hnswTime + "ms");
      System.out.println("Top result: " + hnswResults[0].docid + 
                         " (" + hnswResults[0].score + ")");
    }
    
    // Flat (exact)
    FlatDenseSearcher.Args flatArgs = new FlatDenseSearcher.Args();
    flatArgs.index = "/path/to/flat/index";
    flatArgs.encoder = "TasB";
    
    long flatStart = System.currentTimeMillis();
    try (FlatDenseSearcher<String> flatSearcher = new FlatDenseSearcher<>(flatArgs)) {
      ScoredDoc[] flatResults = flatSearcher.search(query, k);
      long flatTime = System.currentTimeMillis() - flatStart;
      System.out.println("Flat search time: " + flatTime + "ms");
      System.out.println("Top result: " + flatResults[0].docid + 
                         " (" + flatResults[0].score + ")");
    }
  }
}
```

## Available Encoders

Anserini supports various dense encoders:

- **`TasB`** - TAS-B (Topics-Aware Semantic BERT)
- **`Ance`** - ANCE (Approximate Nearest Neighbor Negative Contrastive Estimation)
- **`Auto`** - Auto encoder for MS MARCO
- **`Tct`** - TCT-ColBERT
- **`Dpr`** - Dense Passage Retrieval
- **`Bpr`** - BPR (Binary Passage Retrieval)

Encoders are loaded from `io.anserini.encoder.dense` package.

## HNSW Parameters

### efSearch Parameter

The `efSearch` parameter controls the quality-speed tradeoff:

- **Lower values (50-100)**: Faster search, lower recall
- **Medium values (100-200)**: Balanced performance
- **Higher values (200-500)**: Slower search, higher recall approaching exact

**Example**:
```java
// Fast, lower recall
args.efSearch = 50;

// Standard, good balance
args.efSearch = 100;

// High quality, approaching exact
args.efSearch = 500;
```

## When to Use Each Searcher

### Use HnswDenseSearcher when:
- Index has millions of vectors
- Speed is important
- Approximate results are acceptable (typically >95% recall)
- Real-time search requirements

### Use FlatDenseSearcher when:
- Index is small (under 1M vectors)
- Exact results required
- Computing ground truth for evaluation
- Benchmark or research purposes
