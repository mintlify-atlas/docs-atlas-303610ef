## What is BEIR?

**BEIR** (Benchmarking IR) is a heterogeneous benchmark containing diverse information retrieval datasets. It evaluates the zero-shot capabilities of retrieval models across different domains and task types.

BEIR v1.0.0 includes 18 datasets covering:
- Question answering (Natural Questions, HotpotQA, etc.)
- Fact verification (FEVER, Climate-FEVER)
- Citation prediction (SCIDOCS)
- Duplicate question detection (Quora, CQADupStack)
- Argument retrieval (ArguAna, Touche-2020)
- Bio-medical IR (BioASQ, TREC-COVID, NFCorpus)
- Entity retrieval (DBPedia)
- And more

## Available BEIR Datasets

Anserini supports all 18 BEIR v1.0.0 datasets:

- **arguana**: Argument retrieval
- **bioasq**: Biomedical question answering
- **climate-fever**: Climate science fact verification
- **cqadupstack** (12 variants): Community question answering
  - android, english, gaming, gis, mathematica, physics, programmers, stats, tex, unix, webmasters, wordpress
- **dbpedia-entity**: Entity retrieval
- **fever**: Fact verification
- **fiqa**: Financial question answering
- **hotpotqa**: Multi-hop question answering
- **msmarco**: Passage ranking (distinct from main MS MARCO regressions)
- **nfcorpus**: Medical information retrieval
- **nq**: Natural Questions
- **quora**: Duplicate question detection
- **robust04**: News article retrieval
- **scidocs**: Citation prediction
- **scifact**: Scientific claim verification
- **signal1m**: Tweet search
- **trec-covid**: COVID-19 literature search
- **trec-news**: Background linking
- **webis-touche2020**: Argument retrieval

## Indexing Strategies

Anserini supports multiple indexing strategies for BEIR datasets:

### 1. Flat Indexing

Concatenates the "title" and "text" fields into a single "contents" field:

```bash
python src/main/python/run_regression.py \
  --index --verify --search \
  --regression beir-v1.0.0-arguana.flat
```

### 2. Multifield Indexing

Indexes "title" and "text" as separate fields:

```bash
python src/main/python/run_regression.py \
  --index --verify --search \
  --regression beir-v1.0.0-arguana.multifield
```

### 3. WordPiece Tokenization

Uses WordPiece tokenization (flat indexing):

```bash
python src/main/python/run_regression.py \
  --index --verify --search \
  --regression beir-v1.0.0-arguana.flat-wp
```

```bash
  cqadupstack-english cqadupstack-gaming cqadupstack-gis \

  cqadupstack-webmasters cqadupstack-wordpress dbpedia-entity \
  fever fiqa hotpotqa nfcorpus nq quora robust04 scidocs \
```

## Evaluation Metrics

BEIR uses the following standard metrics:

- **nDCG@10**: Normalized Discounted Cumulative Gain at rank 10 (primary metric)
- **Recall@100**: Fraction of relevant documents in top 100
- **Recall@1000**: Fraction of relevant documents in top 1000
- **MAP**: Mean Average Precision (for some datasets)

Example for ArguAna with flat indexing:

```bash

  -threads 1 \
```

## Typical Retrieval Command

```bash
bin/run.sh io.anserini.search.SearchCollection \
  -index indexes/lucene-inverted.beir-v1.0.0-arguana.flat/ \
  -topics tools/topics-and-qrels/topics.beir-v1.0.0-arguana.test.tsv.gz \
```

## Cross-Dataset Evaluation

BEIR's primary purpose is **zero-shot cross-dataset evaluation**:

<Steps>
  <Step title="Train on one dataset">
    Train your model on a source dataset (e.g., MS MARCO)
  </Step>
  
  <Step title="Evaluate on BEIR">
    Evaluate the same model on all 18 BEIR datasets without any additional training
  </Step>
  
  <Step title="Report aggregate performance">
    Report average performance across datasets as a measure of generalization
  </Step>
</Steps>

This tests how well models generalize to new domains and tasks without fine-tuning.

## Key Insights from BEIR

- **BM25 is competitive**: BM25 remains a strong baseline across many BEIR datasets
- **No single best model**: Different datasets favor different retrieval approaches
- **Domain shift matters**: Models trained on MS MARCO may not generalize well to specialized domains
- **Dense vs. sparse**: Dense models excel on semantic matching; sparse models on lexical matching
