## Overview

`SearchCollection` is the primary class for batch search operations in Anserini. It provides extensive configuration options for ranking models (BM25, Query Likelihood, etc.), query expansion (RM3, Rocchio, BM25-PRF), and specialized search modes (tweets, background linking).

**Package**: `io.anserini.search`

**Source**: `src/main/java/io/anserini/search/SearchCollection.java`

## Constructor

```java
public SearchCollection(Args args) throws IOException
```

Initializes a SearchCollection instance with the provided arguments.

The `Args` class extends `BaseSearchArgs` and contains all configuration parameters for search operations.

## Programmatic Usage

### Basic Search Example

```java
import io.anserini.search.SearchCollection;

public class BasicSearch {
  public static void main(String[] args) throws Exception {
    // Configure search parameters
    SearchCollection.Args searchArgs = new SearchCollection.Args();
    searchArgs.index = "/path/to/lucene/index";
    searchArgs.topics = new String[] { "topics.tsv" };
    searchArgs.output = "run.txt";
    searchArgs.bm25();
    searchArgs.threads = 8;
    
    // Execute search
    try (SearchCollection<?> searcher = new SearchCollection<>(searchArgs)) {
      searcher.run();
    }
  }
}
```

### BM25 with Custom Parameters

```java
SearchCollection.Args args = new SearchCollection.Args();
args.index = "/path/to/index";

  searcher.run();
}
```

## Key Methods

### run()

```java
public void run()
```

Executes the search operation with configured parameters. Processes all topics, performs searches, applies reranking if configured, and writes results to the output file.

### close()

```java
public void close() throws IOException
```

Closes the index reader and releases resources.

## Return Types

SearchCollection writes results to files rather than returning them directly. However, internally it uses:

- **`ScoredDoc[]`**: Array of search results, each containing:
  - `docid` (String): Collection document ID
  - `lucene_docid` (int): Internal Lucene document ID
  - `score` (float): Retrieval score
  - `lucene_document` (Document): Lucene document object

- **`ScoredDocs`**: Object containing arrays of results:
  - `docids` (String[]): Collection document IDs
  - `lucene_docids` (int[]): Internal Lucene document IDs
  - `scores` (float[]): Retrieval scores
  - `lucene_documents` (Document[]): Lucene document objects

## Output Formats

### TREC Format (default)

```
1 Q0 doc1 1 0.9543 Anserini
1 Q0 doc2 2 0.9234 Anserini
2 Q0 doc3 1 0.8765 Anserini
```

Format: `qid iter docid rank score runtag`

### MS MARCO Format

```
1\tdoc1\t1
1\tdoc2\t2
2\tdoc3\t1
```

Format: `qid\tdocid\trank` (tab-separated)
