This guide will get you up and running with Anserini quickly using the prebuilt fatjar. You'll download the toolkit, run a BM25 search on the MS MARCO passage corpus, and evaluate your results.

<Note>
This quickstart uses prebuilt indexes that are automatically downloaded on first use. These can take up significant disk space. See the [prebuilt indexes guide](/indexing/prebuilt-indexes) for more details.
</Note>

## Prerequisites

You need **Java 21** installed on your system. Yes, you need exactly this version.

<CodeGroup>
```bash Check Java Version
java -version
```

```bash macOS (Homebrew)
brew install openjdk@21
```

```bash Ubuntu/Debian
sudo apt install openjdk-21-jdk
```
</CodeGroup>

## Download the Fatjar

<Steps>
  <Step title="Download Anserini">
    Fetch the latest Anserini fatjar (v1.6.0) from Maven Central:
    
    ```bash
    wget https://repo1.maven.org/maven2/io/anserini/anserini/1.6.0/anserini-1.6.0-fatjar.jar
    ```
    
    The fatjar is a self-contained package that includes all dependencies and prebuilt indexes.
  </Step>
</Steps>

## Run Your First Search

<Steps>
  <Step title="Perform BM25 Search">
    Run a BM25 search on the MS MARCO passage corpus using the dev queries:
    
    ```bash
    java -cp anserini-1.6.0-fatjar.jar io.anserini.search.SearchCollection \
      -index msmarco-v1-passage \
      -topics msmarco-v1-passage.dev \
      -output run.msmarco-v1-passage.dev.bm25.txt \
      -bm25
    ```
    
    <Note>
    The first time you run this command, Anserini will automatically download the prebuilt index for MS MARCO passage corpus. This may take several minutes depending on your connection speed.
    </Note>
    
    **What this does:**
    - `-index msmarco-v1-passage`: Uses the prebuilt MS MARCO passage index
    - `-topics msmarco-v1-passage.dev`: Uses the dev query set
    - `-output run.msmarco-v1-passage.dev.bm25.txt`: Saves results to this file
    - `-bm25`: Uses BM25 ranking algorithm
  </Step>
  
  <Step title="Evaluate Results">
    Evaluate the search results using the built-in `trec_eval` tool:
    
    ```bash
    java -cp anserini-1.6.0-fatjar.jar trec_eval -c -M 10 -m recip_rank \
      msmarco-v1-passage.dev \
      run.msmarco-v1-passage.dev.bm25.txt
    ```
    
    **Expected output:**
    ```
    recip_rank              all     0.1840
    ```
    
    You should get an MRR (Mean Reciprocal Rank) of **0.1840**.
  </Step>
</Steps>

## Try Dense and Sparse Vector Search

Anserini also supports modern neural retrieval approaches.

### Dense Vector Search with BGE

Run the same MS MARCO passage search using the BGE dense encoder:

```bash
java -cp anserini-1.6.0-fatjar.jar io.anserini.search.SearchHnswDenseVectors \
  -index msmarco-v1-passage.bge-base-en-v1.5.hnsw \
  -topics msmarco-v1-passage.dev \
  -encoder BgeBaseEn15 \
  -output run.msmarco-v1-passage.dev.bge.txt \
  -efSearch 1000
```

Evaluate:

```bash
java -cp anserini-1.6.0-fatjar.jar trec_eval -c -M 10 -m recip_rank \
  msmarco-v1-passage.dev \
  run.msmarco-v1-passage.dev.bge.txt
```

**Expected MRR:** 0.3575 (significantly better than BM25!)

### Learned Sparse Search with SPLADE-v3

Run search using SPLADE-v3 learned sparse representations:

```bash
java -cp anserini-1.6.0-fatjar.jar io.anserini.search.SearchCollection \
  -index msmarco-v1-passage.splade-v3 \
  -topics msmarco-v1-passage.dev \
  -encoder SpladeV3 \
  -output run.msmarco-v1-passage.dev.splade-v3.txt \
  -impact -pretokenized
```

Evaluate:

```bash
java -cp anserini-1.6.0-fatjar.jar trec_eval -c -M 10 -m recip_rank \
  msmarco-v1-passage.dev \
  run.msmarco-v1-passage.dev.splade-v3.txt
```

**Expected MRR:** 0.4000 (even better!)
