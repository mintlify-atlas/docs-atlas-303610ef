## Overview

`SimpleSearcher` provides a simple, easy-to-use interface for searching Lucene indexes. It's specifically designed for interactive use and to provide a bridge between Java and Python via pyjnius (used by Pyserini).

**Package**: `io.anserini.search`

**Source**: `src/main/java/io/anserini/search/SimpleSearcher.java`

## Configuration Methods

### Scoring Functions

#### set_bm25(float k1, float b)

```java
public void set_bm25(float k1, float b)
```

Configures BM25 as the scoring function.

<ParamField path="k1" type="float" required>
  BM25 k1 parameter (term saturation). Typical values: 0.6-1.2. Default: 0.9
</ParamField>

<ParamField path="b" type="float" required>
  BM25 b parameter (length normalization). Typical values: 0.3-0.75. Default: 0.4
</ParamField>

**Example**:
```java
searcher.set_bm25(0.82f, 0.68f);
```

#### set_qld(float mu)

```java
public void set_qld(float mu)
```

Configures Query Likelihood with Dirichlet smoothing.

<ParamField path="mu" type="float" required>
  Dirichlet smoothing parameter. Typical values: 1000-2500. Default: 1000
</ParamField>

**Example**:
```java
searcher.set_qld(2500f);
```

### Batch Search

```java

                                             List<String> qids, int k, int threads)
```

Searches multiple queries in parallel.

<ParamField path="queries" type="List<String>" required>
  List of query strings
</ParamField>

<ParamField path="qids" type="List<String>" required>

</ParamField>

</ParamField>

**Example**:

## Usage Examples

### Basic Search

```java
import io.anserini.search.SimpleSearcher;

public class BasicSearchExample {
  public static void main(String[] args) throws Exception {
    SimpleSearcher searcher = new SimpleSearcher("/path/to/index");
    
    ScoredDoc[] results = searcher.search("information retrieval", 10);
    
    for (int i = 0; i < results.length; i++) {
      System.out.printf("%d. %s (%.4f)\n", 
          i + 1, results[i].docid, results[i].score);
    }
    
    searcher.close();
  }
}
```

### BM25 Search with Custom Parameters

```java
SimpleSearcher searcher = new SimpleSearcher("/path/to/index");
searcher.set_bm25(1.2f, 0.75f);

ScoredDoc[] results = searcher.search("machine learning", 20);

for (ScoredDoc doc : results) {
  String contents = searcher.doc_contents(doc.docid);
  System.out.println(doc.docid + ": " + contents.substring(0, 100));
}

searcher.close();
```

### RM3 Query Expansion

```java
SimpleSearcher searcher = new SimpleSearcher("/path/to/index");
searcher.set_bm25(0.9f, 0.4f);
searcher.set_rm3(10, 10, 0.5f);

ScoredDoc[] results = searcher.search("neural networks", 10);

// Get feedback terms
Map<String, Float> fbTerms = searcher.get_feedback_terms("neural networks");
System.out.println("Expansion terms: " + fbTerms);

searcher.close();
```

### Multi-Language Search

```java
// Chinese search
SimpleSearcher zhSearcher = new SimpleSearcher("/path/to/chinese/index");
zhSearcher.set_language("zh");
ScoredDoc[] zhResults = zhSearcher.search("信息检索", 10);

// French search

frSearcher.set_language("fr");
ScoredDoc[] frResults = frSearcher.search("recherche d'information", 10);
```

### Batch Search with Multiple Threads

```java
SimpleSearcher searcher = new SimpleSearcher("/path/to/index");
searcher.set_bm25(0.9f, 0.4f);

List<String> queries = Arrays.asList(
    "information retrieval",
    "machine learning",
    "natural language processing"
);
List<String> qids = Arrays.asList("1", "2", "3");

Map<String, ScoredDoc[]> results = searcher.batch_search(queries, qids, 100, 4);

for (Map.Entry<String, ScoredDoc[]> entry : results.entrySet()) {
  System.out.println("Query " + entry.getKey() + ": " + 
                     entry.getValue().length + " results");
}

searcher.close();
```

### Multi-Field Search

```java
SimpleSearcher searcher = new SimpleSearcher("/path/to/index");

Map<String, Float> fields = new HashMap<>();
fields.put("contents", 0.7f);
fields.put("title", 0.2f);
fields.put("abstract", 0.1f);

ScoredDoc[] results = searcher.search_fields("deep learning", fields, 10);

for (ScoredDoc doc : results) {
  Document luceneDoc = doc.lucene_document;
  System.out.printf("%s: %s (%.4f)\n",
      doc.docid,
      luceneDoc.get("title"),
      doc.score);
}

searcher.close();
```
